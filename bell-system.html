Hardware (optional)

Pair a microcontroller (Arduino / ESP32) over Web Serial in Chrome or Edge on desktop. On every bell this page sends the text RING\n so your board can drive a relay or buzzer.

Not connected.

Arduino sketch example (relay/buzzer on pin 13):

void setup(){ Serial.begin(9600); pinMode(13, OUTPUT); }

void loop(){
  if (Serial.readStringUntil('\n') == "RING") {
    digitalWrite(13, HIGH);
    delay(1000);
    digitalWrite(13, LOW);
  }
}

Bell schedule
