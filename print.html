For best results: set 100% scale, disable headers/footers. For CR80 cards use 85.6 × 53.98 mm paper if your printer supports it; otherwise print on A4 at 100% and cut carefully. If printing both sides, print the front first, reinsert the sheet according to your printer, then print the back (or print each page separately).

Print help (duplex, scaling)
  • Always use Actual size / 100% (not “Fit to page”).
  • Turn off browser headers/footers in the print dialog.
  • For duplex: print only Front pages first, flip/reload per your printer manual, then print Back pages (or use two separate print jobs).
  • The sheet size follows your layout: portrait (vertical) card → portrait CR80 page, horizontal card → landscape CR80 page.
  • Exported Both (PDF) contains front then back as two CR80 pages.
